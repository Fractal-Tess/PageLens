# PageLens Knowledge Base

**Generated:** 2026-03-01  
**Project:** PageLens - Website analysis tool built with Tauri, Svelte, and Rust

## Overview

Monorepo containing:

- **Frontend**: Tauri + Svelte 5 desktop app with shadcn-svelte UI components
- **Core Engine**: Rust library (`pagelens-core`) for website analysis (browser automation, SEO, snapshots)
- **CLI**: Rust CLI tool (`pagelens-cli`)
- **Test Apps**: Next.js and SvelteKit apps for integration testing

## Structure

```
pagelens/
├── apps/
│   └── tauri/              # Tauri wrapper + SPA source
│       ├── src/            # Svelte frontend
│       └── src-tauri/      # Tauri Rust backend
├── crates/
│   ├── pagelens-core/       # Rust analysis engine
│   └── pagelens-cli/        # Rust CLI
├── test-apps/               # Next.js & SvelteKit test sites
├── Cargo.toml               # Workspace root
└── package.json             # Bun workspace root
```

## Conventions

### Rust (All Crates)

- Every crate has `prelude.rs` and `error.rs`
- `prelude.rs`: `pub use crate::error::Error; pub type Result<T> = core::result::Result<T, Error>;`
- Errors use `thiserror` derive macro
- Integration tests in `tests/` with `common/mod.rs` utilities

### TypeScript/Svelte

- **Svelte 5** with runes (`$state`, `$derived`, etc.)
- **Tailwind CSS v4** with `@tailwindcss/vite`
- **Vite aliases**: `$lib`, `$events`, `$components`, `$router`
- shadcn-svelte components follow `kebab-case` naming
- IPC types auto-generated to `apps/tauri/src/lib/ipc.ts` via tauri-specta

### Build System

- **Cargo** workspace with `crates/*` and `apps/tauri/src-tauri`
- **Bun** with `apps/*` and `test-apps/*`
- **Turbo** for task orchestration (`build`, `start`)
- **Tauri** for desktop app packaging

## Commands

```bash
# Install dependencies
bun install

# Development (Tauri app)
bun run dev

# Build test apps
bun turbo run build --filter="./test-apps/*"

# Start apps for integration tests
bun run start-apps

# Run Rust tests (requires test apps running)
cargo test -p pagelens-core -- --test-threads=1

# Build everything
bun turbo run build

# Format code
bun format
```

## Testing

- **Unit tests**: Inline in Rust source files
- **Integration tests**: `crates/pagelens-core/tests/` against real test apps
- **Test servers**: Next.js on `:44791`, SvelteKit on `:44792`
- **CI behavior**: Tests fail loudly if servers unavailable (`is_ci()` check)
- **Local behavior**: Tests skip gracefully with warning

| Lint suppression    | `apps/tauri/src-tauri/src/ipc.rs` | `#![allow(clippy::needless_pass_by_value)]`   |

## Notes

- Browser automation uses `chromey` crate (Chromium DevTools Protocol)
- Test apps must be built before running integration tests
- Integration tests run sequentially (`--test-threads=1`) to avoid Chromium port conflicts
- `apps/tauri/src/lib/ipc.ts` is auto-generated - **DO NOT EDIT MANUALLY**
- Each browser test gets isolated `Browser::launch()` instance
- CLI crate has monolithic `main.rs` (~1200 lines) vs modular core
