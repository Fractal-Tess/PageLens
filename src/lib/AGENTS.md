## Conventions

### Svelte 5 Runes

```svelte
<script lang="ts">
  // State
  let count = $state(0)

  // Derived
  let doubled = $derived(count * 2)

  // Effects
  $effect(() => {
    // React to count changes
    console.log(`Count changed to: ${count}`)
  })
</script>
```

### shadcn-svelte Pattern

Components structured as compound components:

```svelte
<script>
  import * as Dialog from '$lib/components/ui/dialog'
</script>

<Dialog.Root>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>
      <Dialog.Title>Title</Dialog.Title>
    </Dialog.Header>
  </Dialog.Content>
</Dialog.Root>
```

## IPC Integration

### Adding a Command (Rust → TypeScript)

1. **Add handler** in `src-tauri/src/ipc.rs`:

```rust
#[tauri::command]
#[specta::specta]
fn my_command(arg: String) -> String {
    format!("Hello {}", arg)
}
```

2. **Register** in `register_ipc_handlers()`:

```rust
.commands(collect_commands![..., my_command])
```

3. **Regenerate bindings** (auto on dev build):

```bash
pnpm tauri dev
```

4. **Use in Svelte**:

```typescript
import { commands } from '$lib/ipc'
const result = await commands.myCommand('world')
```

### ⚠️ CRITICAL

**`src/lib/ipc.ts` is AUTO-GENERATED - DO NOT EDIT MANUALLY**

Changes are made in Rust (`src-tauri/src/ipc.rs`) and regenerated by tauri-specta.
